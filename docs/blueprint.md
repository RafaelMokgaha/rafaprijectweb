# **App Name**: RAFA Project Launcher

## Core Features:

- Hero Section: Display a hero section with a welcome title, subtitle, and buttons to request games or view available ones.
- Game Request Form: Implement a popup form for users to request games. Fields include game name, platform (PC, PS4/5, Xbox, Switch), name, email, and notes. On submit, email rafaproject06@gmail.com with the data.
- Available Games Section: Display available games in a grid layout. Each game card shows the game name, supported platforms, and a 'Request' button. Use images for GTA V ENHANCED, Red Dead Redemption 2, Cyberpunk 2077, Euro Truck Simulator 2, and BeamNG.drive.
- Discord Integration: Include a section to promote the Discord server with a 'Join Now' button linking to https://online-fix.me/.
- Instructions Section: Add a section with a link to SteamTools at https://gofile.io/d/RTQhXE.
- Tutorial Video: Embed a YouTube video from https://www.youtube.com/watch?v=W5tNrA-4xq4 to guide users.

- User login gate: Implement single page login and account creation that prompts users for their name and email to access the site

- Background: Dark purple (#3F3251), emulating a cityscape at night.

- Accent: Deep blue (#4054B2), creating contrast and a glowing effect.
- Titles: 'Oswald' (sans-serif) for a modern, strong feel.
- Body Text: 'Montserrat' (sans-serif) for readability and contemporary style.
- Glowing icons to highlight games, buttons, and interactions, enhancing the neon aesthetic.
- Glassy panels layered over the background, creating depth and a modern, futuristic look. Use soft reflections to emulate the panels.
